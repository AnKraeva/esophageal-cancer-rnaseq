# RNA-seq: плоскоклеточный рак пищевода (GSE164158)

Differential gene expression analysis of esophageal squamous cell carcinoma (ESCC) vs. matched adjacent normal tissue. Nextflow pipeline, Docker containers, public data from GEO/ENA.

## Данные

- **GEO:** [GSE164158](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE164158), BioProject PRJNA689307
- **Дизайн:** 8 пациентов, парные образцы опухоль + прилежащая норма (16 образцов)
- **Секвенирование:** Illumina HiSeq X Ten, paired-end 2×150
- Для разработки используется подвыборка: **первые 10 млн пар ридов** каждого образца (детерминированно, воспроизводимо; параметр `--n_reads`)

### Samplesheet

Список образцов и ссылки на FASTQ получены из [ENA](https://www.ebi.ac.uk/ena/browser/view/PRJNA689307) скриптом на стандартной библиотеке Python (ничего устанавливать не нужно):

```bash
python3 bin/make_samplesheet.py PRJNA689307
```

Скрипт принимает любой accession ENA (исследование, образец или ран) и сохраняет в `metadata/`:
- `ena_runs.tsv` — исходные метаданные ENA (ран, GSM, название образца, число ридов, размер и ссылки на FASTQ);
- `samplesheet.csv` — вход пайплайна: `sample,run_accession,fastq_1,fastq_2`.

Имя образца взято из `sample_title` в ENA: буква – ткань (`N` – норма, `T` – опухоль), число – номер пациента.

## Запуск

Требуется [Nextflow](https://www.nextflow.io/) и Docker.

```bash
nextflow run main.nf -profile docker
```

На Mac с Apple Silicon добавить профиль `arm64` (родные arm64-контейнеры вместо эмуляции amd64; те же программы и версии):

```bash
nextflow run main.nf -profile docker,arm64
```

> [!TIP]
> На Mac добавьте `caffeinate -i` перед командой, чтобы ноутбук не уснул во время расчёта.

На 16 образцах по 10 млн пар (MacBook Air, 8 ядер для Docker) QC + fastp выполняются за 27 мин вместо 1 ч 53 мин с amd64-контейнерами; результаты QC совпадают.

Параметры (`nextflow.config`):
- `--input` — samplesheet (по умолчанию `metadata/samplesheet.csv`);
- `--n_reads` — сколько первых пар ридов скачивать на образец (по умолчанию 10 000 000; `0` — файлы целиком);
- `--outdir` — папка результатов (по умолчанию `results`);
- `--gencode_version` — релиз GENCODE (по умолчанию 50);
- `--lib_type` — тип библиотеки для salmon (по умолчанию `ISF`, проверено на данных; `A` — определить автоматически).

Риды скачиваются из ENA один раз и хранятся в `data/raw/` (`storeDir`): при повторных запусках загрузка пропускается. При обрыве связи задача загрузки перезапускается автоматически (до 3 раз).

Референс GENCODE, таблица tx2gene, отфильтрованные транскрипты и индекс salmon тоже готовятся один раз и хранятся в `data/reference/`.

Пайплайн рассчитан на референс **GENCODE для человека**: адреса загрузки, формат заголовков FASTA (`--gencode`) и разбор GTF заточены под него; параметром задаётся только номер релиза.

Быстрая проверка на одной паре образцов:

```bash
nextflow run main.nf -profile docker --input metadata/samplesheet_test.csv --n_reads 100000
```


## Предварительные наблюдения по подвыборке образца SRR13344601 (N21, 1 млн пар):

### Контроль качества: 

- Качество высокое: средний Q ≈ 35–36 по всей длине обоих ридов.
- Адаптеры: до ~11% ридов к концу прочтения → требуется обрезка.
- В ридах заметна доля некодирующих РНК без поли-А хвоста (7SK, 7SL), что указывает скорее на деплецию рРНК, чем на polyA-отбор (гипотеза).
- **Структура Read 1:** UMI (12 нт) + линкер `GCAGATCGCACA` (12 нт) + 1 переменный нуклеотид, РНК начинается с позиции 26. Видно по составу нуклеотидов по позициям; подтверждено по 7SK RNA и подсчётом (линкер на месте у 94% ридов). Далее в fastp UMI переносится в имя рида, первые 25 нт отрезаются.
- **Ориентация библиотеки:** forward-stranded (Read 1 совпадает с направлением РНК). Проверено BLAST на паре ридов из 7SK (Read 1 — Plus/Plus, Read 2 — Plus/Minus) и подсчётом: 99,8% ридов 7SK в Read 1 в прямой ориентации. Это расходится с протоколом в GEO (NEBNext Directional) и подтверждено salmon (`-l A` → `ISF`, см. ниже).

### Обрезка (fastp):

- UMI (12 нт) перенесён в имя рида, линкер и переменный нуклеотид (13 нт) отрезаны; пики линкера на графике состава нуклеотидов Read 1 исчезли.
- Адаптеры: до ~11,5% ридов к концу прочтения → < 0,4% после обрезки.
- Фильтр прошли 97,7% ридов; средняя длина Read 1 — 120 нт, Read 2 — 139 нт.
- Дупликация Read 1 выросла с 6% до 17% и сравнялась с Read 2: до обрезки её занижал случайный UMI.
- После вырезания UMI в Read 1 стали видны частые последовательности — начала 7SL и 7SK RNA в прямой ориентации, что дополнительно подтверждает
  forward-stranded библиотеку.

## Контроль качества всех 16 образцов (по 10 млн пар)

### Одинаково во всех образцах

- **Структура Read 1 одинаковая:** линкер `GCAGATCGCACA` на позициях 13–24 у 94–95% ридов каждого образца. Проверено по первым 100 тыс. Read 1.
- Адаптеры: до обрезки 10–28% ридов к концу прочтения → не больше 2% после.
- Фильтр fastp прошли 96,6–98,0% ридов; Q30 ≈ 92–93%.
- Дупликация Read 1 после вырезания UMI выросла до 22–29% и сравнялась с Read 2.

### Возможные выбросы: T5 и T13

| | Остальные образцы | T5 | T13 |
|---|---|---|---|
| Адаптеры до обрезки (макс.) | 10–28% | **60–63%** | 27% |
| GC | 49–52% | **55–57%** | 50–51% |
| Дупликация после обрезки (FastQC) | 20–29% | **53–56%** | **50–52%** |
| Средняя длина Read 1 после обрезки | 111–121 нт | **88 нт** | 112 нт |

- **T5:** много коротких фрагментов (адаптер дочитывается, когда вставка короче рида) + высокая дупликация и сдвиг GC – похоже на частично деградированную РНК (гипотеза).
- **T13:** высокая дупликация при остальных показателях в норме – низкая сложность библиотеки или биология (несколько очень сильно экспрессируемых генов); различить можно по UMI.

Пока не исключаем. В salmon оба образца резко выделяются (см. «Квантификация»); решение – по PCA после DESeq2.



## Квантификация (salmon)

**Подход:** selective alignment salmon прямо на транскриптом GENCODE 50 (только основные хромосомы и без выравнивания на геном: STAR требует ~32 ГБ RAM). Для DE на уровне генов это сопоставимо по точности; теряются BAM-зависимые проверки (доля интронных ридов, покрытие по длине гена) и дедупликация по UMI. Опции: `--gcBias --seqBias`, индекс k = 31, без декоев.

**Ресурсы (Apple Silicon, arm64-контейнеры):** индекс – ~3,5 мин, пик памяти 4,3 ГБ; квантификация – ~20 мин на образец (10 млн пар, 4 ядра), пик памяти 3,8 ГБ; все 16 образцов – ~2,5 ч.

**Сводка проверок:** процесс `SALMON_QC` (`bin/salmon_qc.py`) собирает по всем образцам метрики salmon (mapping rate, длина фрагментов, тип библиотеки, специфичность по цепи) и проверки по `quant.sf` (пол по XIST и генам Y-хромосомы – контроль перепутанных образцов, ACTB/GAPDH, доля MT-ридов) и ставит флаги относительно медианы по эксперименту. Таблица – в `results/qc/salmon_qc/` и отдельным разделом в MultiQC. Это проверки, которые можно посчитать без выравнивания на геном; BAM-проверки nf-core/rnaseq (RSeQC, Qualimap, dupRadar) здесь недоступны.

| | Нормы (8) | Опухоли (6) | T13 | T5 |
|---|---|---|---|---|
| Mapping rate | 51,8–58,4% | 47,7–53,3% | **28,0%** | **24,7%** |
| Средняя длина фрагмента | 167–194 нт | 160–173 нт | 148 нт | **108 нт** |
| Тип библиотеки | ISF | ISF | ISF | ISF |
| Совместимость с ISF | 0,91–0,96 | 0,93–0,94 | 0,95 | **0,68** |
| Специфичность по цепи | 0,88–0,91 | 0,87–0,90 | 0,91 | **0,66** |

- **Ориентация ISF у всех 16 образцов** – расходится с GEO (NEBNext Directional → ISR). В пайплайне `lib_type = "ISF"` задан явно; на N3/T3 результат совпадает с `-l A`.
- **Mapping rate ~50%** – ниже типичных 80–90% для polyA-библиотек. Согласуется с гипотезой о деплеции рРНК (интронные риды из пре-мРНК не находят транскрипт); самый частый «ген» почти везде – 7SL РНК (RN7SL1/2, 4–6% ридов).
- **Короткие фрагменты** (160–190 нт при длине рида 150) объясняют высокую долю адаптеров; в опухолях фрагменты короче.
- **Специфичность по цепи ~0,88–0,91** – немного ниже типичных 0,95–0,99.
- **T5:** mapping rate вдвое ниже, очень короткие фрагменты и **потеря специфичности по цепи** (0,66) → вероятно деградация РНК + примесь геномной ДНК (она даёт риды обеих ориентаций и из некодирующих участков). Главный кандидат на исключение.
- **T13:** mapping rate 28% при нормальной специфичности по цепи → не геномная ДНК; вероятно много РНК вне транскриптов (пре-мРНК, неаннотированная транскрипция). Проверить можно индексом с декоями.
- **Пол в парах совпадает у всех 8 пациентов** (XIST против RPS4Y1/DDX3Y; пациенты 4 и 17 – женщины) → образцы не перепутаны.
- **Гены Y-хромосомы снижены в 4 из 6 мужских опухолей** (в 2–9 раз) – возможна потеря Y-хромосомы, частое событие при ESCC; сырые числа, проверим после нормировки.
- **Референс – только основные хромосомы.** `transcripts.fa` GENCODE включает копии генов с альтернативных гаплотипов и патчей, которых нет в GTF: salmon делит между ними риды, а tximport далее их выбросит (так терялось до 90% ридов HLA-B/C, MUC21 и др.). Поэтому добавлен модуль `FILTER_TRANSCRIPTS`, который оставляет в индексе только транскрипты из GTF (670 670 → 644 292).
