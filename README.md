# RNA-seq: плоскоклеточный рак пищевода (GSE164158)

Пайплайн bulk RNA-seq на Nextflow и Docker для анализа дифференциальной экспрессии генов в парных образцах плоскоклеточного рака пищевода (ESCC) и прилежащей нормальной ткани. Данные взяты из открытых баз GEO/ENA. Результатом является таблица дифференциальной экспрессии для отбора генов со значимыми изменениями в опухоли и изучения связанных с ними биологических процессов.


## Данные

В анализ вошли 16 образцов от 8 пациентов с плоскоклеточным раком пищевода. Для каждого пациента сравнивались опухоль и прилежащая нормальная ткань.

| Параметр | Описание |
|---|---|
| Источник | [GEO GSE164158](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE164158) · [ENA PRJNA689307](https://www.ebi.ac.uk/ena/browser/view/PRJNA689307) |
| Секвенирование | Illumina HiSeq X Ten, paired-end 2 × 150 нт |
| Объём анализа | Первые 10 млн пар ридов на образец |

Список образцов и ссылки на FASTQ доступны в [samplesheet.csv](metadata/samplesheet.csv), исходные метаданные ENA – в [ena_runs.tsv](metadata/ena_runs.tsv).

В именах образцов `N` обозначает нормальную ткань, `T` – опухоль, а число – номер пациента: например, `N3` и `T3` образуют пару.

## Запуск

Требуются Nextflow и запущенный Docker. Команды выполняются из корня репозитория.

Полный прогон проверен на Nextflow 26.10.0 с профилем `docker,arm64`.

**Linux x86-64**

```bash
nextflow run main.nf -profile docker
```

**Mac с Apple Silicon**

```bash
nextflow run main.nf -profile docker,arm64
```

### Параметры запуска

| Параметр | По умолчанию | Назначение |
|---|---|---|
| `--input` | `metadata/samplesheet.csv` | Таблица образцов и ссылок на FASTQ |
| `--n_reads` | `10000000` | Число первых пар ридов на образец. `0` – скачать файлы целиком |
| `--outdir` | `results` | Каталог итоговых файлов |
| `--gencode_version` | `50` | Версия референса GENCODE для человека |
| `--lib_type` | `ISF` | Тип библиотеки для Salmon. `A` – автоопределение |

Готовая таблица образцов уже есть в репозитории. Чтобы заново собрать её из ENA, нужно выполнить `python3 bin/make_samplesheet.py PRJNA689307`.

После запуска отчёты качества будут в `results/qc/`, квантификация Salmon – в `results/salmon/`, результаты DESeq2 – в `results/de/`.

Чтобы продолжить прерванный запуск, нужно добавить `-resume` к той же команде. Для переиспользования уже выполненных шагов нужно сохранить `work/` и `.nextflow/`. Скачанные FASTQ и подготовленный референс хранятся в `data/raw/` и `data/reference/`.


## Контроль качества и предобработка ридов

- **Контроль качества.** Все 16 образцов проверены с помощью FastQC до и после обработки. Отчёты объединены в MultiQC.
- **Структура Read 1.** На пробной подвыборке N21 определена структуру начала рида: UMI длиной 12 нт, линкер `GCAGATCGCACA` и один переменный нуклеотид. Линкер на ожидаемой позиции есть у 94–95% проверенных ридов каждого образца.
- **Предобработка.** fastp перенёс UMI в заголовок рида, удалил следующие 13 нт из Read 1, обрезал адаптеры и отфильтровал риды. После обработки сохранилось 96,6–98,0% ридов на образец, а доля ридов с адаптерной последовательностью на конце не превышала 2%.
- **Ориентация библиотеки.** После удаления UMI в Read 1 обнаружены часто встречающиеся последовательности коротких некодирующих РНК 7SK и 7SL. При проверке N21 99,8% ридов Read 1, сопоставленных с 7SK, совпадали с направлением транскрипта. Это указывает на прямую ориентацию библиотеки (ISF в Salmon), тогда как для набора NEBNext Ultra Directional RNA Library Prep, указанного в статье, ожидается обратная ориентация (ISR).
- **Подготовка библиотек.** Частые последовательности некодирующих РНК 7SK и 7SL согласуются с гипотезой о деплеции рРНК – удалении рибосомной РНК при подготовке библиотек.
- **Образцы с отклонениями.**
  - T5 – высокая доля адаптеров до обрезки (60–63%), короткий Read 1 после обработки (в среднем 87 нт) и высокая доля дубликатов после обработки (53–56%). Избыток коротких фрагментов мог быть связан с частичной деградацией РНК или особенностями подготовки библиотеки.
  - T13 – высокая доля дубликатов после обработки (50–52%). Повторяющиеся последовательности могли быть связаны с ПЦР-амплификацией или высокой экспрессией нескольких транскриптов.


## Квантификация (Salmon)

- **Подход.** Salmon сопоставляет очищенные риды с транскриптомом в режиме selective alignment с поправками `--gcBias` и `--seqBias`. Результат для каждого образца сохраняется в `quant.sf`.
- **Референс.** Использован GENCODE v50 (GRCh38.p14). Модуль `FILTER_TRANSCRIPTS` оставляет в FASTA только транскрипты основных хромосом, чтобы индекс Salmon и `tx2gene` содержали один набор транскриптов.
- **Ориентация библиотеки.** Для набора, указанного в GEO, ожидалась `ISR`. Проверка по 7SK и автоопределение Salmon на N3 и T3 указали на `ISF`. Этот тип явно задан в пайплайне.
- **Сводка проверок.** `SALMON_QC` собирает дополнительные метрики из таблицы, оценки экспрессии `ACTB` и `GAPDH` и долю митохондриальных фрагментов. Оценка пола по экспрессии XIST и генов Y-хромосомы совпала внутри всех восьми пар. Полная сводка доступна в `results/qc/salmon_qc/` и MultiQC.
- **Mapping rate.** Медиана по 16 образцам составила 52,4%. Одно из возможных объяснений – деплеция рРНК при подготовке библиотек: часть ридов может происходить из интронов, которых нет в индексе зрелых транскриптов.
- **Образцы с отклонениями.**
    - T5 – низкий mapping rate, короткие фрагменты и сниженная специфичность по цепи.
    - T13 – низкий mapping rate при специфичности по цепи на уровне остальных образцов.

| Метрика | Норма (8) | Остальные опухоли (6) | T13 | T5 |
|---|---:|---:|---:|---:|
| Mapping rate | 51,8–58,4% | 47,7–53,3% | **28,0%** | **24,7%** |
| Средняя длина фрагмента | 167–194 нт | 160–173 нт | 148 нт | **108 нт** |
| Совместимость с `ISF` | 0,91–0,96 | 0,93–0,94 | 0,95 | **0,68** |
| Специфичность по цепи | 0,88–0,91 | 0,87–0,90 | 0,91 | **0,66** |


## Дифференциальная экспрессия

Дифференциальная экспрессия рассчитана в Nextflow с помощью DESeq2. Разведочный анализ и дополнительные графики доступны в ноутбуке [DESeq.ipynb](DESeq.ipynb).
- **Импорт:** результаты Salmon объединены на уровне генов через `tximport` и таблицу `tx2gene`, с `countsFromAbundance = "no"`.
- **Фильтрация:** сохранены гены с каунтом ≥10 хотя бы в 8 из 16 образцов.
- **Нормализация:** учтены различия между библиотеками и эффективные длины, полученные из `tximport`.
- **VST:** преобразование выполнено с `blind = FALSE`, с учётом дизайна при оценке дисперсии.
- **PCA:** использованы 500 генов с наибольшей дисперсией после VST. Образцы T5 и T13 располагались среди других опухолевых образцов. В парный анализ включены все восемь пар.
- **Статистический анализ:** `DESeq()` с парным дизайном `~ patient + condition`; тест Вальда для опухоли относительно нормы.
- **Критерий значимости.** Для отбора генов использован порог `padj < 0.05`.
- **Коррекция эффектов:** `lfcShrink()` методом `apeglm` для более устойчивых оценок `log2FoldChange` при визуализации и ранжировании; исходные `pvalue` и `padj` сохранены. Метод: [Zhu et al., 2019](https://doi.org/10.1093/bioinformatics/bty895).
